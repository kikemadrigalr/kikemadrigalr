## Sobre mí

Desarrollador backend especializado en **APIs REST robustas y escalables con .NET**. Aplico enfoque **API-first / Spec Driven Development** con OpenAPI/Swagger como contrato de integración, con foco en código de alta calidad, refactors seguros y code reviews. ## Cómo trabajo

- **API-first**: el contrato OpenAPI se define antes del código; frontend y backend avanzan en paralelo.
- **Tests que acompañan el código**: pruebas unitarias y de integración en xUnit sobre servicios y lógica de negocio; E2E con Playwright ejecutadas en vivo durante el desarrollo.
- **Refactors seguros**: code reviews y principios SOLID como práctica continua para sostener mantenibilidad a largo plazo.
- **Componentes sobre páginas**: design system reutilizable, lazy loading y módulos desacoplados en Angular.
- **IA como copiloto, no como piloto**: uso Claude Code y Cursor a diario para refactorizar, documentar y depurar, y MCP para conectarlos con las APIs internas del proyecto y con Playwright; la arquitectura y las decisiones las tomo yo.
- **Remoto y presencial**: comunicación asíncrona clara, dailys cortas y entregables visibles, con adaptabilidad a distintos equipos y sectores.
